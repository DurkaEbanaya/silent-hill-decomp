# Inventory PR #190 screenshots

Actual game captures for review, not interface mockups. Desktop screenshots use
an isolated test game with copied memory cards; the Android image is from a real
Android 16 / Adreno phone. No notifications or personal application UI is included.

- `desktop-overview.png`: proportion-preserving panels, portrait/health scan,
  native text, item name/quantity and fully displayed description.
- `desktop-long-weapon.png`: katana in the carousel and equipped-item panel.
  This still image illustrates fit, not proof of stable scale through a full turn.
- `android-device.png`: actual phone rendering after the GLES RGB copy fix.
  English UI with Russian item text is intentional: UI language does not rewrite
  the mounted disc's descriptions. Touch gestures cannot be demonstrated by a
  still image; their validation is described separately in the PR.

Game imagery and underlying artwork retain their original owners' rights.
These screenshots are review evidence, not a new license to the assets.
